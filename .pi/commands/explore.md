# /explore <想法或问题>

只读探索。**不调用 `req_init`、不写 `requirements/`、不改状态**。

参数：<一句话说明你想搞清的事>

## 做什么

1. 读相关代码与 `specs/`（若有），确认现状到底怎样
2. 给 2-3 个可选做法，各一句取舍
3. 判断值不值得做、大概多大体量（T0-T4）、建议走哪条路径
4. 一页纸收尾，不写长文

## 产出（只在对话里给，不落文件）

- 现状：一句话
- 结论：做 / 不做 / 先做别的
- 建议判级：T0-T4 + 理由（一句话）
- 如果做：第一步是什么

用户说「立项」时，再走 `/req-new`，把这份结论灌进 01-intake。
